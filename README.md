# TechFlow · solicitação de proposta

Página estática inspirada na referência visual enviada pelo usuário. Abra `index.html` no navegador ou publique a pasta na raiz de um repositório com GitHub Pages.

O formulário valida os campos e prepara um resumo para cópia. Ele não envia dados a um servidor, pois nenhum endereço ou serviço de recebimento foi informado.
